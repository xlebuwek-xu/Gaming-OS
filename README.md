# Gaming-OS

Gaming OS

An experimental operating system developed from scratch with a focus on understanding low-level system architecture and exploring gaming-oriented performance.
Project Goals

    Develop a custom x86-64 kernel.

    Implement fundamental memory management.

    Explore CPU interrupts and task scheduling.

    Implement keyboard input and a basic command shell.

    Develop graphical output using a framebuffer.

    Create a simple interactive gaming demonstration.

    Measure and evaluate system performance.

Technology Stack

    C

    x86-64 Assembly

    Python

    GNU Make

    QEMU

    GDB

    Git
